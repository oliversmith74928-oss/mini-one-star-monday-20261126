A one-star review of Monday, written as though Monday were a restaurant — 25 words, one line, plain text.

## The line

> Booked a table, waited an hour, server vanished, food came cold, and the bill charged me for a weekend I never ordered. Never again, Monday.

## How it works

`main.py` (Python standard library only) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). It writes nothing anywhere else, and the output is byte-identical on every run.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out1 python3 main.py
MAKEFUN_OUTPUT_DIR=/tmp/out2 python3 main.py
```
